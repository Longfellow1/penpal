# Directory submission drafts

Do not submit these entries as part of this change. The category is a proposed placement; directory taxonomies may use different names.

## Official MCP Registry

**Category:** Memory / developer tools
**Blocked until a package registry release:** the registry only lists servers published to a package registry (PyPI, npm, OCI, …) and verifies ownership through that package. `penpal-mcp` is not on PyPI yet (Homebrew tap only), and the MCP server alone is not useful without the capture daemon. Add `server.json` in the release that first publishes `penpal-mcp` to PyPI (with `mcp-name: io.github.Longfellow1/penpal` in the package README).

> Penpal MCP is a local-first memory layer and stdio MCP server for AI agents on macOS. It records activity from enabled sources, including app and window changes, clipboard content and filtered keyboard text, and imports supported local histories, coding-agent sessions, Git and approved Markdown sources. Claude Code, Codex and Cursor can query the same local store with `search_context`, `get_timeline`, `get_evidence` and `rate_result`. Penpal has no built-in LLM; its database stays on the Mac, while returned context may enter the AI host's conversation and cloud model service.
