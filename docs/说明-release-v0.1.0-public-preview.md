# Penpal v0.1.0 Public Preview

> Historical v0.1.0 release draft for the former Obsidian/report pipeline. It does not describe Penpal MCP 0.3.0; use the repository README for current functionality.

Penpal is ready for early public testing as a local-first Mac companion for Obsidian-native daily reflection.

This release focuses on one core loop:

1. Observe lightweight work-surface signals on macOS.
2. Filter sensitive content before persistence.
3. Write daily reflection notes into the user's own Obsidian vault.
4. Let the user review patterns without turning work into a productivity score.

## What is included

- Menu bar HUD
- Obsidian daily note sync
- Local-first event storage
- App blacklist and field-level privacy filters
- Keyboard chunks and boundaries without raw keystroke logging
- Camera-aware capture pause
- Health checks and recovery paths
- Install and setup flow for macOS

## What is not ready yet

- Windows support
- Mobile companion
- Multi-device merge
- Obsidian community plugin
- Public plugin marketplace
- Cloud account system
