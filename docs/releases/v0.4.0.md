## Penpal v0.4.0

本版在 v0.2.0-preview.1 之后发布，包含原计划的 0.3.0 预览内容（未单独发布）。重点是后台运行可靠，以及升级不必重新授权。

### 系统设置里显示为 Penpal，升级不必重新授权

- 后台采集服务改由 `~/Applications/Penpal.app` 启动，「系统设置 → 隐私与安全性」里的条目显示为 **Penpal**，不再是 `python3.13`。
- App 的签名身份在普通升级中保持不变：`brew upgrade` 之后，已授予的权限继续有效。
- 本机缺少编译工具（clang）时自动回退到旧方式，权限列表仍会显示为 Python，安装时会提示这一点。App 为 ad-hoc 签名，没有开发者证书。

### 后台运行更可靠

- `penpal status`、`penpal doctor` 和菜单栏 HUD 读同一份运行状态，不会再出现一边说正常、一边说停止。
- 升级后，后台服务和 HUD 自动换成新代码，不需要手动重启。从 Penpal.app 打开的 HUD 会自动关闭再重新打开，菜单栏图标不会因此被系统隐藏。
- 新增 `penpal restart`。看门狗限制了自动拉起的次数；`penpal stop` 之后不会被它重新拉起。
- HUD 卡住或菜单栏图标被系统隐藏时，`penpal doctor` 和 `penpal hud status` 会如实报告并给出处理办法。`penpal hud stop` 现在能停掉当前的 HUD。
- 日志写入 `~/.penpal/logs/penpal.log` 并自动轮转。`penpal doctor` 会列出旧版遗留文件，可用 `penpal maintenance clean-legacy` 清理。

### 首次使用与桌面 App

- **首次使用引导**：`penpal install onboard` 先说明数据边界，再逐个确认要开的来源（默认不开），显示所选来源需要的系统权限，最后分批导入历史。导入中断后重跑会从上次位置继续，不会重复入库。
- **可选菜单栏 App**：`penpal app install` 生成 Penpal.app（加 `--login` 开机自启）。界面是重做后的 HUD，包括状态、AI 授权、隐私与删除三部分；它能做的事，CLI 都能做。

### 隐私

- **按项目分桶**：`penpal rules projects` 列出已导入的项目和当前分桶（不显示内容），每个项目一行；可以用规则把某个项目整体归入 Private，`penpal rules rebucket` 让规则作用到已有数据。
- **网站屏蔽**：`penpal privacy block-site` / `unblock-site` / `blocked-sites`，屏蔽会覆盖子域名。被排除的域名不再绕过浏览器历史导入。开启网址观察器时，在被排除网站的标签页里输入、复制的文字和窗口标题，也只保留应用与时间（刚切换标签页的一个检查周期内，可能仍按上一个页面判断）。
- **Claude Code / Codex / Cursor 授权互不影响**：各自使用独立 token；撤销或轮换其中一个，不影响另外两个，被撤销的助手下一次调用就会被拒绝。
- **读不到的来源会说明原因**：文件缺失、没权限、数据库被锁、版本不支持都会写明原因，在 `penpal source list`、`penpal doctor` 和 AI 的查询结果里都能看到，不再默默当成「没有数据」。
- **键盘文字片段**：仍默认开启，只存过滤后的片段。首次运行会打印一次风险说明，`penpal doctor` 显示开关状态。在已授权的分类内可被 AI 搜索，一条命令可关：`penpal source disable keyboard_chunk`。

### 其他

- **睡眠唤醒后自动恢复**：Mac 唤醒后重新检查权限、拉起停掉的采集器并重扫来源。
- **新内容更快可查**：Claude Code / Codex 会话和终端命令历史约 2 分钟内进入记忆。整库复制类来源（如屏幕使用时间、知识库目录）仍约 10 分钟一轮，以免耗电。
- **安装更稳**：修复 README 里 `curl | bash` 一行命令必定失败的问题，以及 Python 3.11 下命令无法启动的问题。每个发布版本都先经过云端 Mac 上的升级演练：从上一个公开版本升级，和全新安装，两种方式都要通过。

### 升级须知

- **从 v0.2.0-preview.1 升级**：请重新运行一次 `install.sh`，或执行 `penpal install init`。旧版后台服务指向带版本号的 Homebrew 目录，`brew upgrade` 后会失效，采集会默默停止；重跑后改为指向稳定路径，以后升级不再受影响。旧版 HUD 会被自动关闭并重新打开。
- **授权一次**：升级后后台改由 Penpal.app 运行，需要在「系统设置 → 隐私与安全性」里给 **Penpal** 授予输入监控、辅助功能和完全磁盘访问权限（读取 Safari 历史需要最后一项）。旧的 `python3.13` 条目可以删掉。以后的普通升级不需要再授权。
- **菜单栏图标不显示**：到「系统设置 → 菜单栏」，把 Penpal 的开关关掉再打开。
- 新装机在运行 `penpal install onboard` 之前，不会读取历史来源（Chrome / Safari 历史、终端命令历史等），实时采集不受影响。已有安装不受此限制。
- 网页地址采集在标准安装中默认开启，需要浏览器自动化权限。不想采集的话，在 `~/.penpal/config.toml` 的 `[watchers]` 里设 `browser_url = false`。
- 仍在试验或未做：中文输入法上屏文字的采集；仅支持 macOS；AI 只能读，不能写回。
